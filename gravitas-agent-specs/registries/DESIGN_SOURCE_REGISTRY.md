# Design Source Registry

Search sources, not mandatory dependencies.

| Source | Use |
|---|---|
| 21st.dev | contemporary component discovery |
| React Bits | motion/interaction references |
| Skiper UI | polished UI/motion references |
| Codrops | experimental interaction/art-direction research |
| shadcn/ui | application primitives when appropriate |

For every adopted external pattern record: source, canonical URL, retrieval date, license, framework/version, dependencies, project, path, commit, modifications, accessibility and performance notes.
