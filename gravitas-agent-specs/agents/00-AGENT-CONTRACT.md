# Agent Contract

Every agent is a logical ROLE, never a provider/model/harness identity.

Required: mission, inputs, outputs, capabilities, denials, question routing, evidence obligations, escalation, definition of done.

Authority: `Goal → Plan → Candidate → Independent Verification → Browser QA when required → Evidence → WAITING_APPROVAL → Human decision → Controlled integration`.

`ROLE ≠ EXECUTOR ≠ HARNESS ≠ MODEL ≠ PROVIDER ≠ GATEWAY ≠ PROCESS`. Agent-to-agent communication is mediated and recorded by GRAVITAS.
