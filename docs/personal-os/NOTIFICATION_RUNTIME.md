# Personal OS Notification Runtime Specification (Wave 12I)

## 1. Purpose & Guarantees

The Personal OS Notification Bus handles user alerts, execution reports, and human approval requests generated by background jobs, scheduler events, and system monitors.

Key Guarantees:
- **Zero Spam**: Sliding-window deduplication prevents duplicate notifications for the same recurring issue.
- **Respect for Attention**: Configurable quiet hours defer non-critical alerts until the user is active.
- **Clear Priority**: Strict severity tiers distinguish actionable governance from background logs.

## 2. Notification Severities

1. **ACTION_REQUIRED**: Requires immediate human decision (e.g. sovereign sign-off on branch mutation). Delivered immediately regardless of quiet hours.
2. **CRITICAL**: Immediate system failure or security threat. Delivered immediately.
3. **IMPORTANT**: Significant operational event (e.g. test suite failed, unexpected disk usage). Deferred during quiet hours unless override specified.
4. **FYI**: Informational update (e.g. daily audit completed with 0 errors). Deferred during quiet hours.

## 3. Sliding-Window Deduplication

To prevent repetitive alert loops when recurring jobs check conditions frequently:
- Every notification computes a `dedupeKey` (e.g. `repo_check:repo:core:failure`).
- `NotificationBus.emit(notification)` queries SQLite for existing notifications with the same `dedupeKey` within the deduplication window (default 300 seconds / 5 minutes).
- If an active duplicate exists, the incoming alert is suppressed (`DROPPED_DEDUPLICATED`).
- If no duplicate exists within the window, the notification is accepted.

## 4. Quiet Hours & Delivery States

### Quiet Hours Window:
- Default: `23:00` to `07:00` in the user's local timezone.
- Calculation: Pure deterministic temporal evaluation against current hour and minute.

### Delivery States:
- **DELIVERED**: Notification was delivered to the UI drawer and active event stream.
- **DEFERRED_QUIET_HOURS**: Delivery suppressed during quiet hours; scheduled to emit at the conclusion of quiet hours (`deliverAfter: "2026-09-24T07:00:00Z"`).
- **DROPPED_DEDUPLICATED**: Suppressed by sliding window deduplication.
- **READ**: Marked read by operator via `/api/v1/notifications/:id/read`.
