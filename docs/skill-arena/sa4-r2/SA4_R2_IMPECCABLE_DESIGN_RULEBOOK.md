## 2. Architectural Role: Design Engineering vs Aesthetic Grammar
- **Universal Design Engineering**: Impeccable provides structural design heuristics: visual hierarchy, typographic scale and measure, touch target minimums, contrast boundaries, and anti-slop rules.
- **Separation of Concerns**:
  - `PRODUCT.md`: Durable product truth (audience, intent, domain constraints).
  - `DESIGN.md`: Project-chosen visual system (design tokens, palette, typography).
  - Surface-Specific Direction: Task-specific requirements.
- **Critical Distinction**: Impeccable does NOT constitute a universal aesthetic grammar. Aesthetic preference remains subordinate to project profiles and sovereign human direction.

## 3. Command & Detector Taxonomy
- **Workflow Commands (24)**: Grouped into Setup (`init`, `onboard`), Creation (`craft`, `shape`, `generate`), Quality Gates (`critique`, `audit`, `harden`), Refinement (`polish`, `distill`, `clarify`), Expressive Tuning (`bolder`, `quieter`, `colorize`, `typeset`, `layout`, `animate`, `delight`, `overdrive`), and Systemization (`adapt`, `optimize`, `extract`, `document`, `live`).
- **Deterministic Detector Rules (61)**: Heuristic rules scanning for anti-patterns:
  - *AI-Slop*: Nested-card proliferation, generic purple-blue gradients, rounded pastel icon tiles.
  - *Typography*: Low-contrast text on colored backgrounds, unconstrained line lengths (>75ch), leading below 1.4.
  - *Layout & Touch*: Sub-44px touch targets, horizontal overflow leaks, arbitrary z-index wars.
