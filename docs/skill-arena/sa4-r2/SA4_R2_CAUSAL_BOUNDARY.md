# GRAVITAS — SKILL ARENA SA4-R2: CAUSAL CLAIM CALIBRATION & GENERATOR CONSUMPTION

## 1. Generator Consumption Mechanism
To establish what causal inferences are scientifically valid, SA4-R2 audited how the deterministic generator processed input prompts:
- **Generator Architecture**: The local generator used preconstructed output implementations and template selections branched on the condition (`CONTROL` vs `TREATMENT`) and the presence of specific candidate capability IDs.
- **Classification**: **`GENERATOR_TEMPLATE_SELECTED_BY_RULE_IDS`** with condition branching.

## 2. Calibration of Causal Language
Because the generator explicitly branched based on condition and rule identifiers rather than passing unconstrained natural language through an autonomous reasoning engine:
- **Disallowed Claim**: Claims that SA4 "directly proves real agent capability improvement" or "proves universal causal efficacy" are unscientific and prohibited.
- **Authorized Claim**: The empirical effect must be stated as:
  **`DETERMINISTIC_GENERATOR_RESPONSE_TO_CAPABILITY_CONDITION`** or **`GUIDANCE_CONDITION_EFFECT_WITHIN_DETERMINISTIC_GENERATOR`**.

## 3. Neutral Length Control Calibration
In SA4, neutral length controls (R21 and R22) added verbose, non-capability text to test whether prompt token count drove output differences.
- SA4-R stated: `NEUTRAL_LENGTH_EFFECT_DISPROVED = true`.
- **SA4-R2 Calibration**: Two deterministic benchmark cases are insufficient to claim a universal scientific law regarding prompt length. The claim is calibrated to:
  **`PROMPT_LENGTH_EFFECT_NOT_OBSERVED_IN_TESTED_CASES`** (`GENERAL_PROMPT_LENGTH_HYPOTHESIS_DISPROVEN = NO`).
