# SA2 Semantic Taxonomy & Relationship Definitions

SA2 strictly adheres to the 10-tier relationship taxonomy:

1. **`EXACT_EQUIVALENT`**: Identical operational directive and effectively verbatim text. Preserves both provenance records without deleting either.
2. **`SEMANTIC_EQUIVALENT`**: Same practical directive, compatible scope, and compatible strength, where neither rule adds an independent condition.
3. **`PARTIAL_OVERLAP`**: Shared semantic territory across different frameworks or domains, but neither rule subsumes the other.
4. **`COMPLEMENTARY`**: Different directives addressing parts of the same objective that cleanly coexist.
5. **`CONTEXT_VARIANT`**: Apparently different guidance reconciled by distinct operating environments (e.g., dense dashboard vs editorial, Android vs iOS).
6. **`VERSION_VARIANT`**: Difference driven by framework, OS, or API generation evolution.
7. **`TRUE_CONFLICT`**: Direct, irreconcilable contradiction in overlapping contexts where following both is impossible or self-defeating.
8. **`APPARENT_CONFLICT`**: Slogan-level contradiction that reconciles upon analyzing context, scope, or preconditions.
9. **`INDEPENDENT`**: No meaningful relationship. Retained in control audit logs; omitted from relationship graph edges.
10. **`UNRESOLVED`**: Insufficient evidence or disputed reviewer classification.
