# SA4 Scoring Rubric & Evaluation Standards

## 1. Objective Assessment Rubric
Objective evaluations execute binary structural assertions:
- **`PASS`**: Code contains required semantic elements, landmark tags, ARIA attributes, interface seams, or numeric alignments.
- **`FAIL`**: Required element is absent or incorrectly mapped.

---

## 2. Subjective Assessment Rubric
Subjective evaluations apply a fixed 5-point discrete ordinal scale:
- **1 = Materially Poor**: Substantially fails visual hierarchy, ergonomics, or layout expectations.
- **2 = Weak**: Barely functional; lacks polish, alignment, or typographical pacing.
- **3 = Acceptable**: Standard baseline implementation; functional but unremarkable.
- **4 = Strong**: High visual hierarchy, clean alignment, cohesive aesthetic.
- **5 = Exceptional**: Production-grade engineering/design polish; flawless tokens, accessibility, and density.

Every subjective score requires an explicit written rationale and paired preference selection (`A_BETTER`, `B_BETTER`, `TIE`, `INSUFFICIENT_EVIDENCE`).
